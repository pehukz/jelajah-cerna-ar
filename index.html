Cara menerbitkan

1. Edit ketujuh organ melalui menu pilihan.
2. Klik Unduh index.html.
3. Unggah file tersebut ke repository GitHub jelajah-cerna-ar, menggantikan file lama.
4. Unggah setiap file .glb yang tersedia ke folder yang sama.
5. Buat QR dengan alamat website ditambah ?organ=mulut, ?organ=lambung, dan seterusnya.

Pratinjau ini hanya menampilkan materi. Model 3D tampil pada website yang diterbitkan. Tombol AR bergantung pada dukungan HP/browser.
